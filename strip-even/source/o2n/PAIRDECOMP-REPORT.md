# Per-pair decomposition of Ψ_n on the flat orthant (n = 6, 8, 10, …)

Scripts (all in this directory, run with the squarepack venv): `core.py` (h, G, A, m1, d, Ψ_n, r*-family), `verify_A.py`, `task1.py` → `task1.json`, `task2.py` → `task2.json`/`task2.log`, `thresholds.py` → `thresholds.log`, `endzero.py` → `endzero.log`, `chain_dp.py` → `chain_dp.log`, `task3.py` → `task3.log`.

## Verdict

**Locally: always exact. Globally: exact only for H above a threshold H_pair(n) ≈ 1.898–1.911 (rising in n); below it the end pairs fail at their origin corner.** The stationarity conditions have a unique solution (n−2 tangential equations, rank n−3, residual ≤ 1e-8), the multipliers are antisymmetric (μ_{n−j} = −μ_j, middle μ = 0), every coefficient is positive, and every g_p has (T_n, 1/T_n) as a local minimizer (box min 0 to 1e-16). At H = 1.95 and 1.99 every g_p is globally minimized there for n = 6, 8, 10, so O2 on the orthant reduces to n−2 two-variable inequalities. At H = 1.9 this holds for n = 6 but fails for n = 8, 10; at H = 1.86 it fails for all three.

The only failure mode is the corner x = Y = 0 of a pair, where g_p = 0 while g_p(T,1/T) = c_x T + c_Y/T − D(T) > 0. With the tangency condition substituted, the end pair fails exactly when 2(2−H)T > D(T) + T D'(T), D(x) = 1 + w − √(w(w+2)), w = x + 1/x. The end coefficient on r1 is forced to be the full 2−H, so the end pair has the largest linear coefficients and fails first. No multiplier choice fixes this (LP over all multipliers, below): the loss is 2.5e-4 (n=8) and 6.6e-4 (n=10) at H = 1.9, and 2.3–2.6e-2 at H = 1.86.

This is an artifact of the decomposition, not a real competitor. Switching off one end pair in the true Ψ_n costs +0.06 to +0.24 (`endzero.log`), because the neighbouring pair loses its deficit too. A chain DP over the exact orthant function (pairs share one coordinate each, so Ψ_n − n is a path-structured sum) on a 0.01 grid of [0,8]^{n−1} finds nothing below F_n − n, except n = 6, H = 1.86, where r = 0 gives Ψ_6 = 6 < F_6(1.86) as expected.

**Fix that works further down:** merge each end pair with its neighbour into a 3-variable block {(1,2),(3,2)}. The block separates given Y2, so it is still 2D work. With the same stationary multipliers, the scheme (two end triples plus single middle pairs) is globally valid for H ≥ 1.86110 (n=6), 1.85205 (n=8), 1.87353 (n=10), 1.88403 (n=12), 1.89433 (n=16), 1.89939 (n=20). For n = 6 and 8 those are exactly H*(n), so nothing is lost. For n ≥ 10 the binding failure moves to the next pair in, (3,4), again at its origin, so blocks of 5 variables are needed lower down. Caveat: grid step 0.01 biases the triple check by up to about +7e-4.

## Method notes
- Pair p contains coordinates (p, p+1); the odd one is x and the even one is Y. The coefficient of |r_j| is a_j in pair j−1 and (2−H) − a_j in pair j, with a_1 = 0 and a_{n−1} = 2−H. The free a_2..a_{n−2} give μ_j = a_j − (2−H)/2.
- Local structure at (T, 1/T): both kink candidates dX and dY are tents with their ridge on xY = 1, and they coincide along it (both equal D(x)). So g_p is a V-shaped valley across the curve, with admissible normal slope interval ≈ [−0.54, 0.42], which all c satisfy easily. The only equality condition is tangential: c_x − c_Y/T² = D'(T). Second order along the curve is convex.
- Global grid: [0,8]² at step 0.01, plus 20 001 points on xY = 1 and its ±1e-4, 1e-3, 1e-2 offsets, plus a 0.001 grid within 0.15 of the point. Local box: radius 0.1 at step 0.0005 plus points on the curve. Tail beyond 8: min(c)·8 − d0 > g_p(pt) holds in every case (`tail_ok`).
- LP: cutting planes over all multipliers maximizing Σ_p min_z g_p (concave in μ). It converged to 1e-7 (LP upper bound minus realized value).

## Task 3 (clipping)
c(H) = √(4/H² − 1): c(1.8469) = 0.41553, c(1.86) = 0.39523, c(1.87) = 0.37930, c(1.9) = 0.32868. Interior odd and even coordinates use the same two-A slope bound for every n, so c(H) does not depend on n. The end condition 2/(3√3) + 1 − H < 0 needs only H > 1.3849; at 1.8469 the slope is −0.462. Sampled one-sided slopes at H = 1.8469 (200k samples): interior ≤ −0.020 for |x| ≥ c, end ≤ −0.59. The wrong-sign allowance becomes 0.4156 instead of 0.38, which changes the K-box bound in Theorem 11 (and the −σ cutoff for general n, not computed here).
